# git_methods

A class that defines methods for working with Git repositories

## Description

The Repo class defines several useful methods for working with
Git repositories.

## Getting Started

### Dependencies

See requirements.txt

### Installing

pip install git_methods

### Executing program

git_methods has no executables

### Using the library

import git_methods
